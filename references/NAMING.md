# 译名纪律（NWNEE 汉化）

专名一致性是汉化质量的命门。Aielund Saga 七章累计修过 44+ 处少数派变体（卡登尼→卡尔德尼、高玛奇→海玛奇、巡林客→游侠……）。本文件是译名相关操作的唯一纪律。Aielund 事实源=`汉化问题/work/译名表.md`；三部曲事实源=`三部曲汉化/三部曲译名表.md`。

---

## 唯一事实源：`work/译名表.md`

- 这是 Act I–IV + Finale 全部译文的**唯一译名基准**。
- **翻译前先读**本表本章节，别凭印象写专名（同一专名会在不同批次反复被引进同一种错写）。
- 本表没有的专名，译完后**补进本表**再继续，不得各批自行其是。
- 表内定案与已交付实文冲突时 —— **改表，不改已交付章节**（已交付的实文才是事实基准）。

### 译名来源口径（已查证）
- 网上有两个民间汉化版（Metatron 2009 Act I / 常年迷路 2012 Act II），但**下载链接全关停**、Act III/IV 从未有中文版。
- 老板裁定：社区习惯译法**仅限已查到的十几个**可用；其余自创名沿用本项目现有译法。
- **官方中文包检索优先级**：官方 NWN 中文包 ＞ D&D 5e 中文（有 3E↔5e 术语差）＞ Aielund 自造名（无官方可依）。

## 查表铁律（三部曲定案，2026-10-17）

生物/规则术语的译名，**按固定优先级查表，不许凭印象**：

1. **先查官方 TLK**：`三部曲汉化/work/server_tlk_utf8.tsv`（星空娱动官方 server.tlk，GBK→UTF-8），**EN 列精确匹配**（实测 116,150 行）——官方译过的一律沿用官方定名。
2. 官方没有 → 查 **3.5 SRD 中文镜像**（工作区 `wiki/DND-3.5-中文SRD/topics/`，怪物按首字母分文件如 `怪物【H】.htm`；原豆包聊天目录已迁走）。
3. 都没有 → 自译，并补进三部曲译名表。

**官方定名节选**（EN 列实查所得）：
- devil=**魔鬼** / demon=**恶魔**（严格区分，禁混用）
- Rakshasa=邪兽鬼、Invisible Stalker=隐形潜伏怪、Howler=嚎兽（SRD）、Lemure=劣魔（SRD）
- Mephit 各系=灰/泥/岩浆/风魔蝠；Greater=**超大型**（前缀）/ Huge=**巨型** / Elder=「X元素长老」
- Dire=**凶暴**（前缀）
- ⚠️ Witch's Wake 官方**未译**（TLK row 110655 保留英文）；「女巫苏醒/守夜/保留英文」待老板裁定。

## 改定案的三步顺序（铁律）

```
先改表 → 再批量替换 cn_*.txt 与 batch_*.json（两处都要改）→ 最后重新 backfill
```

- ⚠️ **两处都要改**：只改 `cn_*.txt` 不回填白改；只改 `batch_*.json` 下次 apply 会被覆盖；只改表不回填实文不变。
- 大批量改名**先 `cp` 到 `backups/<日期>_<序号>_<事由>/`** 再动。

## 审计 / 改名工具（都在 `work/`）

```bash
# 译名一致性审计：打印"译名表定案 vs 各章实文"计数，同名词两种写法即报警
$PY _name_audit.py <ch...>              # 如 _name_audit.py act2 act3 act4p1 act4p2

# 同原文不同译法：专抓【跨章复用池引入的错译】（Cuthbeort 就是这么揪出来的）
$PY _variant_scan.py <ch...>

# 定向改名（先备份再替换）
$PY _fix_archmage.py <ch...>            # 受影响文件先备份再改

# 繁体字扫描（只报需转写的字）
$PY _chk_hans.py <ch>

# 官方中文包字节级检索（别用全量解析，会超内存被 SIGTERM 杀）
$PY _q_tlk2.py "<关键词>"
```

**使用纪律**：每章译完 / 任何批量改名后，跑一次 `_name_audit.py` + `_variant_scan.py` 复验。

## 子串假阳性陷阱（扫描时必看原文）

单纯字符串计数会把下列判成"不一致"，**实际是假阳性**，必须逐条看原文：
- 「影德鲁伊」是「暗影德鲁伊」的子串
- 「陈」是「陈先生」的子串
- 「游侠」是「游侠团」的子串
- 「晨」常出现在「清晨 / 晴晨」里的正常字（只有 utc 名 `Chen` 那 1 处是真的）
